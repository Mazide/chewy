# chewy

iOS-тамагочи про еду: юзер фоткает приём пищи, Gemini оценивает пропорции тарелки
(не калории), герой реагирует, юзер копит монеты и тратит на косметику (одежда, лагерь,
темы). Ощущение — мультик, не приложение. SwiftUI + SpriteKit; UI-прототип — `prototype/`
(React + Storybook). Соло-инди проект.

## Сборка

- Проект: `chewy/chewy.xcodeproj`, схема `chewy`, iOS Simulator.
- `xcodebuild -project chewy/chewy.xcodeproj -scheme chewy -destination 'platform=iOS Simulator,name=iPhone 16' build`
- Gemini-ключ: `Secrets.plist` с `GEMINI_API_KEY` в бандле (не в git). Без ключа работает `MockFoodAnalyzer` — для UI-работы ключ не нужен.

## Карта доков (docs/)

- `DESIGN.md` — персонаж, кор-луп, формула награды, тюнинг-константы. Источник истины по дизайну.
- `TODO.md` — задачи. NEXT = Сборка 1, порядок пунктов = порядок сборки.
- `USER_FLOW.md` — основной цикл, побочные экраны, day-in-life.
- `VALIDATION.md` — гипотеза, метрики, пороги решений. Пороги заморожены, не двигать.
- `DECISIONS.md` — журнал решений с причинами. Новое решение → строка сюда.
- `AGENT_BACKLOG.md` — задачи для автономной работы Claude («бери A1» / «бери следующую»):
  правила автономии, критерии готовности. Скоуп не расширяет, исполняет TODO.
- `spec/SPEC_v5.md` — инженерная спека Сборки 1 (экраны, юзкейсы, слои, acceptance,
  стыковка с A-задачами). v1–v4 — история итераций. При работе по A-задачам читать v5.

## Инварианты дизайна (нарушать нельзя ни в коде, ни в копирайте)

1. **Ноль цифр наружу**: никаких ккал/БЖУ/процентов/веса в UI. Вид героя, речь, тарелка секторами; цифры — только стрик и монеты.
2. **Герой никогда не умирает**: дно — `hungry` (грустит, костёр тлеет). Никаких game over.
3. **Джанк не наказывается**: любой лог = стрик жив + минимум монет. Джанк — реакция героя (`sluggish`), не упрёк.
4. **Грусть героя — только за молчание** (нет лога), чисто визуальная: ничего не отнимается; ночью герой спит. Единственная оговорка — стрик-«уголёк»: 1 пропуск дня замораживает стрик (костёр тлеет), 2+ подряд — гаснет; рекорд не сгорает никогда.
5. **Без стыда в текстах**: герой — друг, не тренер и не диетолог. Никаких «ты переел», «плохая еда», диет-лексики.
6. **Накопленное не отнимается**: косметика, стрик-рекорд, прогресс — назад не откатываются.

## Процесс

- **Заморозка скоупа**: во время Сборки 1 новые идеи → только в `TODO.md` IDEAS / «После сигнала». NEXT не растёт.
- Новая механика: сначала DESIGN.md + TODO, потом код.
- Решения с причинами — в DECISIONS.md, одной строкой.
- Доки на русском, код и коммиты на английском.
- Тюнинг-цифры живут в `GameConfig.swift` (когда появится) — в доках на них только ссылаться, не дублировать.
