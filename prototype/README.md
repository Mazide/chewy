# chewy — Storybook

Черновые канвасы и соответствующие примеры с контентом для всех экранов Chewy.
Сейчас обсуждаем полный набор и доводим визуал; iOS — после согласования.
Порядок — [MVP_PLAN](../docs/MVP_PLAN.md), принципы и покрытие —
[SCREEN_STUDIES](../docs/SCREEN_STUDIES.md), сценарии — [USER_FLOW](../docs/USER_FLOW.md).

## Запуск

```bash
cd prototype
npm ci
npm run dev             # http://localhost:6006
npm test                # очередь снимков, биомы и время суток
npm run build           # storybook-static/
```

`npm run storybook` и `npm run build-storybook` — равнозначные команды.
Браузер автоматически не открывается. Изображения из `public/` раздаются по `/assets/`.

## С чего начать

- [Core/Canvas — все канвасы](http://localhost:6006/?path=/story/core-canvas--all-screens).
- [Core/Sandbox — все экраны с контентом](http://localhost:6006/?path=/story/core-sandbox--all-screens).
- [Рюкзак с примеркой](http://localhost:6006/?path=/story/core-sandbox--backpack).
- [Путь](http://localhost:6006/?path=/story/core-sandbox--path).

Справа выбираются экран и размер телефона: 320 × 568, 390 × 844, 430 × 932.
Там же описан композиционный принцип и доступны демосостояния.
На экранах лагеря и пути есть «Мир лагеря · проба»: продвижение по 27 стоянкам
через девять биомов — лес, озеро, рощу, луг, грибной лес, морской берег, каньон,
горную долину и снежный перевал. Есть ручное время суток и часы Europe/London.
Дорогу можно прокручивать, кнопка прицела возвращает к своей стоянке. Просмотр
другого места не перемещает героя; прогресс пока демонстрационный и не сохраняется.
Внутри телефона работают переходы: лагерь → камера/галерея → лагерь → результат,
дневник → конкретная запись, рюкзак → применение → лагерь.

15 экранов/состояний: лагерь, дневник, камера, галерея, обработка, результат,
рюкзак, путь, знакомство, имя, напоминания, камера недоступна, нет сети,
не удалось узнать еду и неуверенный анализ. Они используют общую логику;
в канвасе иллюстрации заменены блоками, в Sandbox показан подготовленный контент.
Отдельные истории дают пустой день, пустой рюкзак, первую встречу, возвращение
и три оформления анализа: лабораторию, алхимию, компьютер.

## Как убрать лишние страницы и экраны

- В полном Storybook выбери страницу слева, затем **Экраны → Удалить эту страницу**
  в верхней панели. Убирается только выбранная история; другие варианты остаются.
  Там же **Удалённые страницы → Вернуть** восстанавливает её на прежнем месте.
- В песочнице справа выбери **Экран → Удалить экран из списка**. Убранные пункты
  доступны в **Удалённые экраны → Вернуть**. Список общий для канвасов и проб с контентом.
- Это два независимых списка для ревью: удаление страницы Storybook не удаляет
  тип экрана, а удаление пункта селектора не удаляет отдельные истории слева.
  Макеты, фотографии и переходы внутри сценария приложения сохраняются.
- Выбор переживает перезагрузку и синхронизируется между открытыми вкладками
  того же адреса. Он хранится только в этом браузере (`chewy.review-archive.v1`),
  отдельно от еды и настроек лагеря. На другом устройстве список будет исходным.
  Даже если удалить все пункты, восстановление остаётся доступным.

## Что моделируется

Снимок сразу создаёт локальную демозадачу. Можно перезагрузить страницу и вернуться:
готовность определяется сохранённым временем завершения. Обработка в фоне не запускается.
На результате меняются название, детали и порция; повтор обновляет ту же запись,
предыдущий результат остаётся в дневнике до нового. Фото сохраняет свою идентичность.

Камера показывает фото-пример; галерея содержит три подготовленных снимка.
AI, сеть и системные разрешения не вызываются. Проблемные состояния — отдельные
визуальные примеры. В рюкзаке шесть представительных вещей; цены взяты из прежнего
демо, инвентарь живёт до перезагрузки. Одна активная вещь каждого типа — условность
этой пробы. Награды за еду и покупки пока не соединены в общую экономику.
Имя и напоминания показывают сценарий знакомства, реальные уведомления не включаются.

## Сохранённые пробы

- `Core/Canvas` → «Лагерь · композиция блоками»: «Треугольник», «Больше воздуха»,
  «По диагонали». Независимые «Сегодня» и «+ Еда»; старые варианты панелей доступны
  для сравнения. Блоки можно двигать, масштабировать, перемещать стрелками.
- `Core/Canvas` → «Сегодня · походный дневник»: раскрытие маленькой страницы в записи
  дня; четыре демосостояния. Escape, крестик и нажатие снаружи сворачивают её обратно.
  При уменьшении движения переход выполняется без перемещения и масштаба.
- `Core/Canvas` → «Добавить еду · камера и анализ»: отдельный стенд с выбором задержки,
  ручным завершением обработки и сбросом демоочереди.
- `Core/Sandbox` → «Песочница · лагерь слоями»: редактор PNG-слоёв, опоры/тени,
  видимость и размеры. Есть отдельная композиция по раскладке владельца.
  Позиции сохраняются локально по размерам; сброс касается только выбранного макета.
  В новых сценариях перетаскивание выключено для проверки нажатий.
- `Core/Skeleton`: исходный грубый каркас.

## Где менять

- `src/core/ScreenStudy.jsx`, `screen-study-data.js`, `screen-study.css` — экраны,
  композиция, примерка, путь, знакомство и состояния.
- `ForestPath.jsx`, `journey-world.js`, `WorldLighting.jsx` — карта, биомы и освещение.
- `StudyMedia.jsx`, `study-content.js`, `screen-study-content.css` — переключение
  блоков на контент и его оформление; исходники в `public/assets/screen-studies/`.
- `study-generation.json`, `study-image-bounds.json` — происхождение и границы нового арта.
- `AddFoodCanvas.jsx`, `add-food-canvas.css`, `capture-session.js` — камера, галерея,
  ожидание, результат; ключ хранения `chewy.capture-study.v1`.
- `FoodJournal.jsx`, `food-journal.css` — компактная страница и раскрытие дневника.
- `CampCompositionCanvas.jsx`, `camp-composition-presets.js` — композиции лагеря.
- `CampSandbox.jsx`, `camp-sandbox.css`, `sandbox-assets.js`, `sandbox-scene-layout.js`,
  `sandbox-placement.js` — слои, геометрия, опоры, редактор и сохранения расстановки.
- `sandbox-image-bounds.js` — видимые границы PNG; `sandbox-owner-preset.js` — раскладка владельца.
- `public/assets/sandbox/camp-v3-flat/` — плоский набор сцены; герой остаётся исходным
  кадром `archive-reference/hero_idle_sheet.png` без перегенерации.
- `CoreSkeleton.jsx`, `CoreCanvasView.jsx`, `src/data/game.js` — прежний каркас и демоданные.
- `*.stories.jsx` — истории трёх секций.
- `archive/legacy-prototype/`, `archive/standalone-canvas/` — сохранённые прежние пробы;
  архивы не участвуют в сборке и не раздаются публично.

Результаты локальной проверки и скриншоты — `shots/screen-studies/` (вне Git).
Финальное согласование внешнего вида, текста и продуктовых правил ещё впереди.
