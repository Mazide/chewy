# chewy — Storybook

Рабочая песочница без медиа. Порядок — [MVP_PLAN](../docs/MVP_PLAN.md),
сценарии — [USER_FLOW](../docs/USER_FLOW.md).

## Запуск

```bash
cd prototype
npm ci
npm run dev             # Storybook → http://localhost:6006
npm run build           # сборка → storybook-static/
```

`npm run storybook` и `npm run build-storybook` — равнозначные команды.
Браузер автоматически не открывается.

## Секции

- `Core/Skeleton` — каркас экранов крупными блоками.
- `Core/Sandbox` — отдельная песочница: пробный лагерь из независимо сгенерированных
  PNG-слоёв, переключение видимости, рамки/опоры и галерея ассетов. Герой крупнее,
  предметы стоят основаниями на земле с контактными тенями; порядок перекрытий
  зависит от положения основания. Кнопки имеют подложки, подписи и нажатие,
  открывают существующие экраны скелета в окне для пробы.
  «Контакт с землёй» в инспекторе переключает плотные тени под подошвами/поленьями
  и траву перед краями для сравнения; чайник частично перекрывает костёр.
  «Композиция · по твоей раскладке» — отдельная проба по скрину владельца:
  крупный герой, палатка позади, костёр/чайник слева, пёс справа. Своё сохранение;
  сброс возвращает именно этот пример. Геометрия — `sandbox-owner-preset.js`.
  Есть контрольные размеры 320 × 568, 390 × 844, 430 × 932 и переключатель в инспекторе.
  По умолчанию включено перетаскивание: двигать предметы, боковые кнопки,
  область еды и основное действие мышью или пальцем. Стрелки — точное перемещение,
  Shift — крупный шаг, Escape отменяет текущий drag. Тени и трава следуют за
  предметом, перекрытия пересчитываются по опоре. За края макета предмет не уходит.
  У выбранного объекта зелёный угол рамки меняет размер с сохранением пропорций;
  в инспекторе есть ползунок и «Исходный размер». Для наземных предметов сохраняется
  точка опоры (кроме ограничений края экрана), тени/трава масштабируются вместе с ними.
  Раскладка и размеры сохраняются в localStorage отдельно для каждого экрана; «Сбросить
  этот экран» очищает только его позиции. Для проверки переходов выключить
  «Перетаскивать предметы и кнопки». Это инструмент песочницы, не механика игры.
- `Core/Canvas` — тот же набор экранов и сценариев: будущие изображения показаны
  прямоугольниками с диагоналями и подписями содержимого (фон, герой, костёр, фото еды).

В каждой секции: связанный цикл с лагеря, лагерь после еды, длинный список,
обзор всех экранов, добавление еды, результат, путь и рюкзак. Оба представления
используют один компонент и общую логику. Отдельного приложения канваса нет.

Композиция на ревью; оформление еды перед героем — предложение.
Фото заменено примером, анализ мгновенный, состояние сбрасывается при перезагрузке.
Демоданные и экономика не означают согласования правил.

## Где менять

- `src/core/CoreSkeleton.jsx` — общие экраны и переходы, режимы `skeleton` / `canvas`.
- `src/core/CoreCanvasView.jsx`, `core-canvas.css` — схема размещения изображений и подписей.
- `src/core/canvas-layout.js` — черновые размеры областей и требования к содержимому;
  подписи на канвасе показывают размеры отображения, не разрешение исходного арта.
- `src/core/core-skeleton.css` — оформление скелета.
- `src/core/*.stories.jsx` — две параллельные секции Storybook.
- `src/data/game.js` — необходимые демоданные, не источник утверждённых правил.
- `src/core/CampSandbox.jsx`, `camp-sandbox.css`, `sandbox-assets.js` — аппликация лагеря.
- `src/core/sandbox-scene-layout.js` — геометрия сцены, опоры, размеры и безопасные
  области контрольных макетов; сцена и интерфейс рассчитываются отдельно.
- `src/core/sandbox-placement.js` — смещения перетаскивания, границы и формат
  локального сохранения раскладки и размеров. Старые сохранённые позиции читаются.
- `src/core/sandbox-image-bounds.js` — видимые границы PNG по alpha. При смене
  картинок пересчитать; прозрачные поля не должны влиять на положение ног/основания.
- `public/assets/sandbox/camp-v3-flat/` — активный плоский набор: фон, палатка,
  костёр, чайник, пёс, карта, рюкзак. Все созданы отдельно под архивного героя.
  Герой — исходный кадр спрайтшита (`archive-reference/`), выделенный через CSS
  без перегенерации. Паки `camp-v1/` и `camp-v2/` сохранены как прошлые варианты.
- `src/core/sandbox-flat-generation.json` — точные промпты встроенного image_gen
  и происхождение всех семи новых изображений.
- `src/core/sandbox-generation-v2.json` — файлы и точные промпты предыдущего пака
  встроенного image_gen. `sandbox-generation.json`, `sandbox-prompts.json` сохраняют
  историю первой пробы.
- `archive/legacy-prototype/` — прежние экраны, компоненты, медиа и скрипты.
- `archive/standalone-canvas/` — отложенная проба отдельной страницы канваса.

Архивы не участвуют в сборке и не раздаются как публичные файлы.
