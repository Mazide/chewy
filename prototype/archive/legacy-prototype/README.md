# Архив прежнего прототипа

Временно убран из рабочей песочницы по просьбе владельца. Здесь сохранены старый
связанный прототип, экраны, компоненты, вайрфреймы, темы, медиа и вспомогательные
скрипты. Пути внутри каталога повторяют прежнюю структуру `prototype/`.

Архив не подключён к Storybook, Vite и раздаче публичных файлов. Это исторические
заготовки, не источник текущих продуктовых правил. Для возврата нужных частей
переносить их обратно выборочно после сверки с согласованным скелетом.

`src/data/game.js` сохранён также в архиве для целостности старого демо. Его рабочая
копия остаётся в `prototype/src/data/`: текущий скелет использует расчёт тарелки,
демонаграды и цену фонаря. Эти значения не означают согласования экономики.

Скрипты имеют прежние ограничения путей Linux, Chromium и ffmpeg; перед запуском
их нужно адаптировать. Медиа не удалены и могут понадобиться на этапе оформления.
