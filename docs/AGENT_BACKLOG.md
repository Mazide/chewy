# chewy — Агентский беклог

> Задачи, которые Claude делает автономно, без твоих решений по ходу.
> Протокол: скажи **«бери A1»** (или «бери следующую») — задача делается целиком, в конце
> короткий отчёт. Устал — кидаешь одну строку, остальное само.
>
> Скоуп = TODO.md (NEXT). Беклог его не расширяет, только исполняет.
> Обозначения: ⚙️ код · 🔎 ресёрч · 📄 док. Порядок A-задач = порядок зависимостей.

## Правила автономии

- Агент сам: пишет код + тесты, гоняет сборку (`xcodebuild`), правит доки, ресёрчит.
- Агент НЕ решает сам: новые механики, изменение инвариантов, тюнинг-значения (только
  переносит из DESIGN), финальные тексты речи героя (драфты — ок), арт.
- Всплыл дизайн-вопрос внутри задачи → не решать, отложить и вернуть вопросом в отчёте.
- Результат = изменения в worktree + зелёная сборка/тесты + отчёт. Коммит — только по команде.
- Готовую задачу отмечать [x] здесь; решения по ходу — строкой в DECISIONS.md.
