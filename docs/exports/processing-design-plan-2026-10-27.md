# Обработка · связь со снимком

> Исторический снимок этой итерации, не текущая очередь. Часть рекомендаций уже
> выполнена последующими пробами. Актуальные состояния — [SCREEN_STUDIES](../SCREEN_STUDIES.md),
> задачи — только [TODO](../TODO.md).

Проблема из ревью владельца: отдельная сценка с героем и большим прибором
не объясняет, что происходит с отправленной едой и куда вернуться за ответом.

- Цвета: бумага `#f8efd7`, рамка фото `#fff7df`, чернила `#493c2c`,
  лесной зелёный `#38594b`, латунь `#b49a69`. Акцент алхимии — приглушённый
  лиловый, компьютерной темы — шалфей. Одна композиция для всех тем.
- Шрифт: ui-rounded / Avenir Next / system-ui; статус 20 px, пояснения 12 px.
- Композиция: заголовок «Разбор еды», подтверждение сохранения, крупный снимок
  с небольшим движущимся инструментом, миниатюры других кадров при наличии,
  один статус и раскрываемые детали. Внизу постоянно доступен выход в лагерь.

```text
← Разбор еды
         ✓ Фото сохранены
        ┌─────────────┐
        │  фото еды   │
        │      лупа   │
        └─────────────┘
          [1] [2] [3]
        • Разбираем еду
          Что разбираем ⌄

     Можно закрыть приложение.
      Результат будет в лагере.
           [В лагерь]
```

Проверка плана: сохраняем предметный язык камеры и бумагу результата.
Прибор всегда над самой едой, без отдельного лагерного фона и второго героя.
Движение означает только незавершённую обработку; процентов, оценок времени
и придуманных этапов распознавания нет. При reduced motion инструмент статичен.
Повторный запрос показывает новый набор фото и статус уточнения; прежняя запись
остаётся в дневнике. Подтверждение сохранения не подменяет состояние анализа.

Для ревью состояние «Обработка» в инспекторе фиксируется до нажатия
«Показать результат». Реальный сценарий из камеры по-прежнему завершает
демо-анализ сам. Это управление примеркой, не механика приложения.

Проверить три размера, три оформления, один/несколько кадров, раскрытие деталей,
уточнение записи, уход/возврат и автоматическое завершение настоящей демозадачи.


## Результат примерки

Снимок стал главным объектом, надписи разделяют сохранение и текущий анализ.
Убраны герой, фон лагеря и крупный прибор, конкурировавшие с едой. При визуальной
проверке исправлены квадрат фото и высота миниатюр: закрытый компактный экран
с двумя кадрами полностью помещается. Выход остаётся неподвижным при раскрытии
длинного комментария. Три темы сохраняют одно расположение элементов.

Сборка и четыре набора тестов успешны; сценарии отправки, выбора кадра, уточнения,
ухода и завершения пройдены через UI. Реальный анализ по-прежнему моделирует таймер.
Вариант подготовлен для ревью владельцем, принятие нового вида ещё не зафиксировано.
