## Промпт

Use case: illustration-story.
Asset type: background art layer for a portrait mobile game screen, approximately 1:2 aspect ratio.
Create a NEW forest journey scene belonging to exactly the same simple hand-drawn cartoon world as the reference images. Reference 1 is the existing camp background: match its thin dark warm outlines, large simple rounded tree silhouettes, muted olive meadow, deep forest green, warm brown trunks and pale blue sky. Reference 2 is the existing tent and only demonstrates the same flat illustration style; do NOT draw tents in this background.
The scene is a wide grassy forest clearing viewed from a gentle elevated angle, with a pale sandy footpath winding into the distance, trees framing both sides and overlapping bushes creating depth. This is a place one can walk through, not a paper map or diagram. Use broad simple shapes, almost flat fills, very restrained shading, few tiny details, no painterly brush texture, no 3D.
The mobile screen will place interactive camping objects on top. Leave FOUR open grassy camping clearings along the trail: near 43% width / 29% height, near 72% / 43%, near 30% / 57%, and a larger foreground clearing near 60% / 72%. Keep these clearings free of trees and props. The path connects these clearings organically and continues towards the bottom. Edges can contain a few rocks and simple grass tufts. Top 14% should be a quiet sky opening for a header; bottom 16% uncluttered meadow for a UI overlay. The actual playable scenery fills the middle.
No characters, no animals, no tents, no campfires, no furniture. Those are separate layers. No text, numbers, labels, badges, UI, borders, parchment, pins, icons or watermarks. Preserve the camp reference's friendly, simple cartoon proportions and quiet daytime mood. Make the background fill the entire portrait image.
