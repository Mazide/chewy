## NEXT — завершение основного прототипа

Каждый пункт соответствует одному этапу MVP_PLAN; подробные критерии не дублируем.
Выполненный этап отмечаем здесь, хронику отдельных примерок сюда не дописываем.

- [x] **0. Аудит и документация.** Проверены документы, активный код, iOS-заготовка,
  ассеты и сборка; актуальные источники отделены от истории. [Отчёт](PROJECT_AUDIT.md).
- [ ] **1. Упорядочить Storybook.** Один вход «Прототип», отдельные «Состояния» и
  «Мастерская»; убрать точные дубли, старый Skeleton и отложенное знакомство из
  основного маршрута. Проверить зависимости перед переносом старых файлов/арт-паков.
- [ ] **2. Согласовать поведение.** Разобрать Q1–Q7 в [DESIGN](DESIGN.md#вопросы-перед-сборкой-единого-прототипа)
  на примере еды, занятия Чуви и возвращения. Утвердить или исключить каждый спорный
  элемент из текущего объёма; зафиксировать правила и причины до кода.
- [ ] **3. Связать одну демосессию.** Еда → результат → герой/выбранный прогресс →
  рюкзак/лагерь/путь. Общее сохранение, воспроизводимые примеры и полный сброс;
  применение каждой вещи видно в соответствующем экране. Пройти первый и повторный заход.
- [ ] **4. Завершить состояния.** Связать ошибки/неопределённость/повтор с той же
  задачей; уточнение, удаление/отмена, поздний ответ и смена дня — по USER_FLOW и
  решениям этапа 2. Проверить отсутствие дублей и потери сохранённых данных.
- [ ] **5. Довести визуал.** Согласовать все обязательные экраны, состояния героя,
  тексты, арт и движение; проверить три размера, плотный контент и доступность.
  Генерировать только отсутствующие материалы для уже выбранных сцен.
- [ ] **6. Принять и передать.** Пройти критерии MVP_PLAN, заполнить матрицу
  SCREEN_STUDIES и сведения для переноса в ASSETS/USER_FLOW, зафиксировать проверенную
  сборку и явное согласование владельца. Нативная реализация начинается отдельной работой.

## IDEAS / После сигнала

Это парковка, не дополнительная очередь. Решения о текущем core обсуждаем на этапе 2;
отсюда ничего не переходит в реализацию без выбора владельца.

| Направление | Сохранённые идеи / где подробности |
|---|---|
| Жизнь лагеря | Дела героя, следы в биомах, привычки, завершение цели, «обжить → сделать своим»; пример скамейки и разделение базовых вещей/оформления — NUTRITION_HABITS. Расширение за пределы выбранного core отложено |
| Новые занятия | Просьбы героя, вылазки/находки, коллекция, рост кемпа, недельные квесты, дополнительные истории биомов |
| Косметика | Гамак, чайник, спальник, фляга, верёвка, карта на пне; одежда и дополнительные темы. Типы/слоты не считаются согласованными |
| Представление еды | Пикник, гирлянда снимков, тропинка дня, миниатюры вокруг тарелки; порции как зелья; кольца лишь возможная форма, не выбранный редизайн |
| Дополнительные возможности | История журнала по дням, профиль, звук/haptic, вариативные сценки, Live Activity, виджет, vacation mode, Apple Watch, мультиплеер |
| Отдельный продуктовый этап | Онбординг, имя, добровольные напоминания, пейвол/монетизация, финальное название |
| Производство и исследования | ComfyUI/ControlNet для спрайтов, анализ конкурентов при конкретном вопросе; старые предложения — архив SPEC §16 |

Подробные прежние предложения, выполненные итерации и задачи после прототипа
сохранены в [архивном снимке](archive/PROTOTYPE_NOTES_2026-10-28.md).
План нативной сборки/беты здесь не ведём; VALIDATION сохраняет замороженные пороги.
