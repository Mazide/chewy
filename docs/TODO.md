| Dynamic Island | [ActivityKit / Live Activities](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities): после отправки фото показывать Чуви и фактический статус разбора, дать переход к записи/результату. Активность привязана к задаче и завершается вместе с ней; без процентов, выдуманных стадий и постоянного питомца в островке. Надёжная фоновая обработка реализуется отдельно |
| Интеграция с App Intents | [App Intents](https://developer.apple.com/documentation/AppIntents): быстрый вход в камеру Chewy через Siri, Shortcuts и Spotlight; через Controls — с экрана блокировки, Control Center и Action Button на поддерживаемых устройствах. Переиспользовать существующий сценарий добавления еды |
| Дополнительные возможности | Расширение истории журнала сверх выбранного просмотра дней через «Путь», профиль, звук/haptic, вариативные сценки, vacation mode, Apple Watch, мультиплеер |
| Отдельный продуктовый этап | Пейвол/монетизация, финальное название. Онбординг, имя и добровольные напоминания вынесены в начатый отдельный этап выше |
| Работа с художником | Владелец допускает полную перерисовку и новый авторский стиль, если понравится; генерации можно использовать как референс. Сохранить это в будущем брифе. Найм, бюджет и смена стиля не утверждены; действующие пороги VALIDATION не меняются |
| Производство и исследования | ComfyUI/ControlNet для спрайтов, анализ конкурентов при конкретном вопросе; старые предложения — архив SPEC §16 |
