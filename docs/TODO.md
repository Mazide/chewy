1. **Зафиксировать единицу производства.** Референсы и бриф → рисунок из частей
   → редактируемый мастер Rive → анимации/состояния → превью/QA → пакет выпуска.

2. **Сохранить ручные правки.** Разделить первоначальное создание рисунка и
   последующие сборки. У героя такая защита уже есть; распространить принцип

3. **Собрать единый выпуск на костре.** Переиспользовать текущие CLI и скрипты:

   файлов и не перерисовывает предмет. Затем повторить процесс на палатке.
4. **Подготовить управление состояниями.** Пять состояний выбранного костра,
   переходы и reduced motion; приложение задаёт визуальное состояние, игровой
   тюнинг остаётся снаружи Rive. Пороги не утверждаются этой технической пробой.

   и измерения на устройстве остаются частью последующей нативной проверки.
