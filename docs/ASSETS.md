# chewy — Манифест ассетов Сборки 1

> Скелеты экранов: `prototype/` Storybook → **Wireframes/** (7 экранов, номера зон → сюда).
> Процесс: скелет заморожен → генерим пак → подставляем в прототип → ревью → в iOS.

## Пайплайн генерации

- **Статика** (фоны, панели, иконки, декор) — image-API (Gemini image / gpt-image) с
  **style-anchor**: в каждый промпт референсом идут готовый фон кемпа + герой из `assets/`
  (cartoon, bold ink outlines, Adventure Time-палитра). Просить **прозрачный PNG** для
  всего, что не фон.
- **Анимации** (герой, костёр) — Kling → spritesheet, как раньше (DECISIONS 2026-06-12).
  API-генерация консистентный спрайтшит не тянет.
- Пачка = один стилевой преамбул-промпт + вариации по позициям; ревью подстановкой в
  Storybook (скелет уже размечен зонами).

## Пак C — темы анализа ×3 (таверна/лаборатория/магия) · gen-API

На тему: фон, оправа фото-окна (котёл/линза/шар), проп (вилка/колба/гримуар),
иконки стопов порции ×3, «назад»-предмет. Вывеска — из пака A с перекраской.
Таверна — базовая (бесплатная), lab+magic — товары рюкзака.

## Пак E — герой · Kling (не API!)

| Спрайт | Статус |
|---|---|
| idle | ✅ есть (121 кадр) |
| eating, happy | ✅ есть в коде |
| **hungry** | ❌ дорисовать — блокер (ось потребности) |
| **sluggish** | ❌ дорисовать — блокер (реакция на джанк) |
| Онбординг-виньетки ×3 | собрать композицией из готовых ассетов, не генерить |

## Иконки товаров (= каталог, ~18–20 шт) · gen-API

Декор из пака B в иконочном виде + питомцы + превью тем. Один промпт-шаблон
«item icon, transparent, ink outline», пачкой.

## Порядок (что блокирует Сборку 1)

1. Спрайты hungry + sluggish (Kling) — без них нет оси потребности и реакции на джанк.
2. Костёр ×3 состояния — уголёк-стрик не читается.
3. Хром пака A (вывеска, свиток, пергамент, кожа, монета, орбы).
4. Каталог: декор-PNG в сцену + иконки товаров.
5. Темы C (2 платные — контент магазина).
6. Пак D-биомы — после сигнала (IDEAS).
