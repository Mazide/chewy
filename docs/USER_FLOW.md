# chewy — User Flow

> Флоу сборки 1 (валидация). Луп: «покорми → герой поработает → вернись забрать → потрать внимание».

---

│                                                             │

---

## Между сессиями (аппка закрыта)

```
Виджет на Home Screen телефона:
  герой + статус + прогресс таймера труда ("мастерит...")

Таймер дошёл → находка готова → пуш: "Чуи что-то нашёл для тебя!"
Долго не кормили → hungry → starving → пуш: "Чуи ждёт тебя у костра"
Ночь (quiet hours) → герой спит, таймеры на паузе, пушей нет
```

---

## Сессия B — следующий заход (часто = следующий приём пищи)

```
┌─────────────────────────────────────────────────────────────┐
│                        HOME SCREEN                          │
│            🎁 НАХОДКА: открыть → в коллекцию                │
│            (дроп-таблица: обычная / редкая)                 │
│                                                             │
│   Герой смотрит на тарелку дня → новая ПРОСЬБА:             │
│        💬 "сегодня было мало овощей... хочу зелёного"       │
│                                                             │
│   Герой снова hungry → ждёт Сессию A                        │
└─────────────────────────────────────────────────────────────┘
```

Каждая сессия закрывается заданием на следующую: луп тянет ожиданием, не только таймером.

## Day in the Life

**08:15 — Завтрак.** Герой спал ночью (quiet hours), проснулся `hungry`. Висит вчерашняя
просьба: «хочу зелёного». Овсянка с ягодами, обычная порция → `happy`, энергия, герой ушёл
в вылазку.

**13:30 — Обед.** Пуш не нужен — юзер сам сел есть, рефлекс «покормить Чуи». Сначала забирает
находку (сессия B), потом фоткает курицу с гречкой (сессия A) → `energized`, просьба про белок
выполнена → ×2 энергии. Новая просьба: «а овощей-то мало сегодня».

**16:00 — Перекус пропущен.** Герой `hungry`, виджет грустнеет. В 18:00 пуш: «Чуи что-то нашёл +
проголодался».

**19:45 — Ужин.** Открыл с пуша → находка в коллекцию. Фоткает пиццу, большая порция → герой наелся,
но `stuffed` + `sluggish`: сонный, медленный. Без упрёка — стрик жив, лог честный.
💬 «уфф… тяжеловато. завтра найдём что-нибудь свежее?»

**23:00 — Ночь.** Герой спит. Тарелка дня: белка много, овощей мало → завтрашняя просьба готова.

---

## Правила (зашиты во флоу)

- Залогировал что угодно → стрик жив, минимум энергии есть. Джанк = реакция героя, не наказание.
- Деградация только за молчание (не логировал), и только днём.
- Просьба не выполнена → ничего плохого, висит дальше.
- Герой никогда не умирает.

## Открытые вопросы из флоу

- [ ] Тайминги: часов до hungry / starving? Длина таймера труда — фикс 3 ч или от качества еды?
- [ ] Стак: покормил во время работы героя — энергия копится или таймер продлевается?
- [ ] Первая сессия дня: показывать «итог вчера» или сразу просьбу?
- [ ] Пуш «находка готова» и пуш «голодает» — объединять, если совпали?
