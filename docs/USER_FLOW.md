# chewy — User Flow

> Луп: «сфоткай еду → герой отреагировал → монеты → потрать на красоту».
> Прототип флоу кликабелен: `prototype/` Storybook → Flow/ChewyApp.

---

## Основной цикл (~30 сек)

```
ЛАГЕРЬ (хаб)
  герой + кемп, монеты, лог приёмов, тарелка дня
  иконки: 🗺️ журнал · 🧭 путь · 🎒 рюкзак
        │ FAB «Add Food»
        ▼
АНАЛИЗ (стилистика = тема: таверна / лаборатория / магия)
  📷 фото еды · порция 3 стопа (без процентов) · FEED!
        │ Gemini: пропорции тарелки
        ▼
РЕЗУЛЬТАТ
  реакция героя: happy / sluggish (energized, stuffed — фразами до валидации)
  💬 вердикт фразой (без стыда) · сектора тарелки · +🪙
        │ Back to camp
        ▼
ЛАГЕРЬ — тарелка дня дополнилась, стрик жив, монеты выросли
```

## Побочные экраны (из лагеря)

- **🗺️ Журнал дня** — свиток: настроение героя, тарелка дня секторами, лог приёмов.
- **🧭 Путь героя** — пергамент-карта: тропа по дням, костры 🔥/🟠/⚫, стрик.
- **🎒 Рюкзак** — купить/надеть: одежда, питомец, декор лагеря, темы анализа.
  Экипированное появляется в сцене лагеря; тема меняет скин анализа.

## Day in the Life

**08:15 — Завтрак.** Овсянка с ягодами → `happy`, +монеты, сектор злаков подрос.
**13:30 — Обед.** Курица с гречкой → `happy`, белок дня закрыт. Монет хватило на фонарь.
**19:45 — Ужин.** Пицца, большая порция, злаки дня уже полны → вклад ~0, `sluggish`
(«stuffed» — фразой). Без упрёка: стрик жив, минимум монет начислен.
💬 «уфф… тяжеловато. завтра что-нибудь свежее?»
**Вечером.** Зашёл в путь: 🔥 6 дней, сегодняшний костёр горит.

---

## Правила (зашиты во флоу)

- Залогировал что угодно → стрик жив, минимум монет. Джанк = реакция героя, не наказание.
- Монеты = вклад приёма в тарелку дня; полные сектора вклада не дают (умеренность встроена).
- Стрик-уголёк: пропуск дня — замер (костёр тлеет), 2+ подряд — погас; рекорд навсегда.
- Герой никогда не умирает и не упрекает.
- Накопленное (косметика, стрик-рекорд) не отнимается.
