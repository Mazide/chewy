# Чуви: видео как опора для векторной анимации

Цель этой пробы — перенос жеста из сохранённого видео на **общий векторный риг**.
Владелец уточнил, что растровая упаковка `hero-video-pilot` не решала задачу:
кадры нужны как опора для поз и времени, а итог должен оставаться гибким.

Исходный эпизод — рука к виску, затем обе руки у часов. Это один проход;
последняя поза отличается от первой. Повтор начинается явно с начала.

## Процесс

1. Сравнить исходные PNG и вручную разметить опорные позы в координатах
   исходника 506 × 1060. Отдельно отметить неясные суставы и дефекты генерации.
2. Перенести ориентиры на существующий векторный рисунок Чуви, сохраняя общую
   структуру частей, опору стоп и читаемость плеч, локтей и кистей.
3. Сохранить движение в нативных ключах и костях Rive. Промежуточные положения
   создаёт риг; отдельного рисунка для каждого видеокадра нет.
4. Проверить позы и время рядом с исходным роликом, исправить перекрытия и
   деформации. Совпадение пикселей не является критерием для другого рисунка.
5. Собирать сохранённый мастер без повторной генерации исходника.

Это проба с ручной разметкой опорных кадров. Автоматическое распознавание
суставов и универсальный конвертер произвольного видео в риг здесь не реализованы.

Новые кисти, часы и деформации — черновик для художественного ревью.

## Что находится внутри Rive

Результат — [chewy-vector.riv](exports/chewy-vector.riv), **14 627 байт**.
Внутри нет `Image` / `ImageAsset` и нет растровых кадров. Сохраняется общий
рисунок с отдельными векторными контурами и нативными ключами костей.

Из 12 вручную размеченных поз для переноса использованы 11: кадр 99 с
неясным пересечением пальцев исключён. Для кистей скрипт подбирает повороты
двух костей с постоянной длиной; ориентир локтя задаёт сторону сгиба.
Опорные точки приблизительные. Маленькая ошибка попадания в эти точки
не доказывает точного совпадения с настоящими суставами или исходным движением.

Рука слева на экране при движении состоит из двух векторных частей на костях
с округлым перекрытием у локтя. Исходный контур этой руки виден в `Rest`.
Рука справа использует нативные `Skin`, `Tendon` и веса вершин.
Такой составной рукав устраняет разрывы при смене стороны сгиба, найденные
в первой попытке деформировать старый цельный контур. Линия нахлёста ещё заметна.

24 из 26 исходных фигур сохранены как точные поддеревья; менялись рукава.
Ладонь у виска, составной рукав и часы — дополнительные черновые детали.
Их художественная приёмка открыта. Наличие костей не означает готовности
любого будущего ракурса, жеста или каталога одежды.

| Элемент | Значение |
|---|---|
| Artboard / state machine / view model | `ChewyReference` |
| `action` | `0` — `Rest`, `1` — `ReferenceGesture` |
| Жест | 121 кадр при 24 FPS, 5,0417 секунды, `oneShot` |
| Конец | Поза с часами удерживается |
| Повтор | `action=0`, один шаг state machine, затем `action=1` |
| Взгляд | `lookX`: −12…12, `lookY`: −8…8; по умолчанию оба 0 |
| Рабочий мастер | [chewy/scene.rml](chewy/scene.rml) |
| Паспорт выпуска | [exports/manifest.json](exports/manifest.json) |

`.riv` — файл для воспроизведения; редактируемый источник этой пробы — RML.
Экспорт редакторского `.rev` требует авторизации Rive CLI; ручной круг через
Rive Editor и Apple runtime в этой пробе не проверены.

## Повторить проверку

Сборка читает сохранённый мастер и компилирует временную копию. Ни разметчик,
ни `author_vector.py` при сборке не вызываются; ручные правки не перезаписываются.

```sh
python3 content-pipeline/rive/hero-vector-reference/pipeline.py --rive /tmp/chewy-rive-cli/bin/rive
```

Нужны Rive CLI 1.8.0, Python с Pillow и NumPy. Локальный выпуск проверяет
отсутствие изображений, контракт, настоящие кадры CLI в 24 моментах,
неподвижность стоп, границы и удержание последней позы через 6 и 10 секунд.
Хеши источников должны совпадать до и после сборки.
Результат — [native-qa.json](exports/native-qa.json).

При запущенном локальном сервере:

```sh
node content-pipeline/rive/hero-vector-reference/check_motion.mjs http://127.0.0.1:6015/hero-vector-reference/preview/review.html --out content-pipeline/rive/hero-vector-reference/exports/browser-qa
```

Для браузера нужны Playwright/Chromium из `prototype/package-lock.json` и FFmpeg;
используется сохранённый WebGL2 runtime 2.40.1. Проверка включает управление,
независимый взгляд, прозрачность, телефонную ширину, reduced motion и работу
самостоятельного `.riv` без запросов изображений. Сам по себе запрет запросов
не доказывает отсутствие встроенных изображений — это проверяет структура мастера.
Художественная приёмка не выводится из технических проверок.

Браузерный прогон прошёл на сохранённом выпуске: настоящий WebGL2,
`action=0/1` через state machine, однократное завершение без таймера просмотрщика,
пауза/повтор, взгляд и сброс, reduced motion, мобильная ширина и повтор загрузки.
Проверка обработчика скрытой вкладки моделирует событие и разрыв времени;
это не проверка фоновой политики операционной системы.
Фазы жеста узнаваемы, но промежуточные положения рук и силуэт отличаются
от исходного видео. Особенно внимательно смотреть подъём и опускание руки;
технический отчёт не утверждает точности художественного совпадения.

[Независимый аудит](evidence/independent-rig-audit.json) проверил 28 поз и
совпадение повторной сборки по байтам. На временных копиях по одному ключу
предплечья изменено на 0,12 радиана: слева изменились связанные векторные
части, справа — деформируемый рукав. Противоположная рука и нижняя часть тела
в обеих пробах сохранились попиксельно. Рабочий источник остался неизменным.
[Сравнение этих правок](evidence/independent-perturbation-contact.png) показывает
проверенную гибкость рига в малом диапазоне; произвольные новые позы из этого
не следуют автоматически.
