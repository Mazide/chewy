# Черновик сменной одежды

Работа отложена по просьбе владельца 31 октября и записана отдельной задачей
в [TODO / Редактор героя](../../../docs/TODO.md#редактор-героя).

Основа — актуальная версия облачного героя `2696405`, полученная через CLI
в `references/hero-from-editor.rml`. Сохранены его ручные трансформации,
лицо, волосы, кисти и исходные четыре дорожки движения. Исходный облачный файл
не перезаписывался; этот черновик в Rive не загружен.

`scene.rml` — отдельный редактируемый источник: исходная одежда `Camp` и
черновой походный комплект `Trail`. View Model `Wardrobe`, enum `outfit`
со значениями `camp` / `trail`; отдельный слой state machine переключает
прозрачность групп одежды. Верх остаётся под дыханием, низ и обувь неподвижны.
`make_draft.py` служит только для первичного создания и отказывается
перезаписывать существующий `scene.rml`.

Проверено: CLI verify — 0 ошибок и предупреждений, inspect — без problems;
статичные рендеры обеих одежд просмотрены:
[исходная](exports/camp.png), [походная](exports/trail.png).
Не проверены переключение туда-обратно во время движения, круг ручных правок
через Editor и композиция с лагерем. Текущий импортёр `hero-editable`
предназначен для одного artboard без View Model, поэтому данный черновик
нельзя подставить в основной источник без доработки зависимостей.

Повторить рендер (CLI сейчас установлен в `/tmp/chewy-rive-cli/bin/rive`):

```sh
rive content-pipeline/rive/hero-wardrobe --data=outfit=camp --advance=1 --screenshot=content-pipeline/rive/hero-wardrobe/exports/camp.png
rive content-pipeline/rive/hero-wardrobe --data=outfit=trail --advance=1 --screenshot=content-pipeline/rive/hero-wardrobe/exports/trail.png
```

Комплекты или независимые слоты, финальный арт и продуктовый каталог
остаются открытыми решениями.
