# Один векторный лагерь · проба Rive

Отдельная проба по запросу владельца 31 октября 2026. Сначала проверяем
чистый вектор; смешанный вариант можно сравнить с ним отдельной работой.
Это черновик производства, не утверждённая замена основного лагеря.

## Смотреть

- [Сцена в движении](exports/scene.mp4).
- [Зацикленное превью](exports/scene.webp).
- [Исходники рядом с векторами](exports/comparison.png).
- [Настоящий runtime-файл](exports/camp-scene-vector.riv).
- [Отчёт проверок](exports/qa.json), [состав сборки](exports/inspect.txt).

Интерактивный просмотрщик: из корня репозитория запустить

```sh
python -m http.server 8771 --bind 127.0.0.1 --directory content-pipeline/rive/camp-scene-vector
```

Открыть [локальный стенд](http://127.0.0.1:8771/preview/). Он воспроизводит
тот же `.riv` через Rive WebGL2; можно остановить движение и открыть любой
предмет крупно. Runtime и WASM лежат рядом, внешние CDN при просмотре не нужны.
Видео и WebP доступны прямо из чата без запуска сервера.

## Что перенесено

| Материал | Перенос и движение |
|---|---|
| Лесная поляна | Силуэты исходного фона, неподвижные деревья и трава |
| Палатка | Отдельные контуры ткани, входа и складок; колышки, растяжки и опоры неподвижны |
| Герой | Перерисовка исходной позы; лёгкое дыхание, наклон головы, моргание; ноги и ботинки закреплены |
| Пёс | Отдельные хвост, голова, ухо и глаза; лапы закреплены |
| Костёр | Переиспользованы геометрия и движение принятого по направлению `campfire-base`; меняются контуры пламени, поленья неподвижны |
| Чайник | Неподвижный корпус, три независимые струйки пара |

Все видимые элементы `.riv` — векторы. Растровых ассетов, видеокадров и
скриптов внутри нет. PNG использованы только как референсы; их пути и SHA-256
сохранены в [manifest.json](manifest.json). Рисунки восстановлены вручную
в коде с упрощением фактуры; это не автоматическая конвертация без потерь.
Композиция подготовлена для отдельного теста и не заменяет раскладку владельца.

## Контракт

- Главные artboard и state machine: `CampScene`, 390 × 844.
- Пять самостоятельных artboard: `Tent`, `Hero`, `Dog`, `Campfire`, `Kettle`.
  Название state machine совпадает с названием соответствующего artboard.
- Общий цикл — шесть секунд. На главной сцене предметы подключены как
  `NestedArtboard` со своими `NestedStateMachine`.
- Компоненты прозрачные; фон есть только у `CampScene`.
- Игровых входов, пяти ступеней наполнения, реакции на еду и ночи в этой
  пробе нет. Она проверяет рисунок, независимое движение и сборку сцены.
- Reduced motion — пауза runtime в просмотрщике; пользователь может запустить
  движение явно. Отдельной продуктовой механики из этого не следует.

Runtime-файл: 375 518 байт (около 367 KiB). Вес web runtime считается отдельно.
Исходник RML заметно больше runtime-файла: в нём сохранены читаемые ключи
движения вершин, а не только сжатый экспорт.

## Воспроизвести

Нужны Rive CLI 1.8.0, Python с Pillow/NumPy, ffmpeg и шрифт Noto Sans.
В текущем окружении CLI — `/tmp/chewy-rive-cli/bin/rive`.

```sh
python content-pipeline/rive/camp-scene-vector/build_scene.py
rive content-pipeline/rive/camp-scene-vector --verify
rive inspect content-pipeline/rive/camp-scene-vector --summary
python content-pipeline/rive/camp-scene-vector/render_previews.py --rive /path/to/rive
```

`build_scene.py` задаёт размещение, собирает риги и перезаписывает `scene.rml`.
Геометрия и движение предметов находятся в `*_art.py`; костёр импортируется
из соседнего `campfire-base/`. Исключение — герой: его рабочий источник теперь
[`hero-editable/scene.rml`](../hero-editable/scene.rml). Сборка читает документ,
сохраняет его байты и ID, а для общей сцены переназначает ID только у копии.
`hero_art.py` — исходная заготовка, повторно для героя не вызывается.
Ручная правка контуров и возврат из редактора описаны в
[инструкции](../hero-editable/README.md).
`render_previews.py --stills` делает только кадры, сравнение и QA.

Для локального воспроизведения достаточно `.riv`. Редактируемые исходники —
Python/RML. Для отдельного героя экспортирован
[`hero-editable.rev`](../hero-editable/exports/hero-editable.rev);
полный круг через Editor ещё не проверен.

## Что проверено и что остаётся

CLI verify и inspect: без ошибок, предупреждений и problems. В реальном
рендере каждого artboard проверены движение, замыкание ключей и стык петли;
нижняя часть героя, лапы пса и основание костра неподвижны. Сравнение
исходников и векторов просмотрено визуально. Это техническая проверка,
не художественная приёмка.

В [браузерной проверке](preview/qa.json) пройдены загрузка настоящего `.riv`,
переключение всех шести artboard, пауза и продолжение, видимый неподвижный
первый кадр при reduced motion и мобильная ширина. Ошибок JavaScript и внешних
сетевых запросов нет. [Скриншот просмотрщика](preview/review.png).

Основной Storybook и iOS не изменены. Apple runtime, производительность,
память и батарея на iPhone ещё не проверялись. Рисунок, амплитуды и посадка
предметов ждут ревью владельца; выбор технологии для всего продукта открыт.
