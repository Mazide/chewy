# Управляемый герой: техническая проба Rive

2 ноября 2026. Отдельный редактируемый риг для проверки программного управления
движением, одеждой и реквизитом. Основной лагерь, его раскладка, игровые сохранения
и облачный файл Rive не меняются. Это **не финальная походка и не готовый эпизод
жизни лагеря**.

Рабочий источник — [scene.rml](scene.rml), runtime —
[exports/hero-actions.riv](exports/hero-actions.riv). Сборка и проверка читают
сохранённый RML, не генерируют его заново. `.riv` содержит один векторный artboard,
общий набор суставов, две одежды и отдельную палочку с маршмеллоу. Видеозапись
просмотра может служить примером, но приложение управляет самим ригом.

## Контракт

| Элемент | Имя / значения |
|---|---|
| Artboard и state machine | `HeroActions` |
| View Model / instance | `HeroControls` / `Default` |
| enum `action` | `idle`, `walk`, `sit`, `reach` |
| enum `outfit` | `camp`, `trail` |
| enum `prop` | `none`, `stick` |
| number `rootX`, `rootY` | Положение общего корня в artboard; исходно `700`, `1040` |
| number `facing` | `1` или `-1`, горизонтальное отражение вокруг корня |
| Размер artboard | `1400 × 1120`, с местом для вытянутой руки и палочки |

Безопасный горизонтальный диапазон в просмотрщике — `rootX: 600…800`:
проверены обе стороны и все действия с палочкой без обрезания по краям.

`walk` движет конечностями на месте. Перенос по лагерю задаёт приложение через
корень или контейнер проигрывателя; маршрут не записан в анимацию. `sit` задаёт
сидящую позу и положение руки для палочки, `reach` — вытянутую руку. Все пары
действий переключаются через короткое смешивание; одежда и реквизит меняются
независимо и не запускают движение сначала. Все действия цикличны, кроме самого
перехода между ними; завершение занятия и взаимодействие с предметом пока
не моделируются.

В web runtime стенд использует `autoBind: true` и
`drawingOptions: rive.DrawOptimizationOptions.AlwaysDraw`, чтобы обновлённые
привязки рисовались и при ручном показе кадра на паузе. После загрузки:

```js
const controls = player.viewModelInstance;
controls.enum('action').value = 'walk';
controls.enum('outfit').value = 'trail';
controls.enum('prop').value = 'stick';
controls.number('rootX').value = 750;
controls.number('facing').value = -1;
```

В просмотрщике доступны `await chewyHero.ready`, `chewyHero.set({...})`,
`pause()`, `resume()`, `reset()` и `state()`. Пауза останавливает проигрывание
и рендер; смена одежды на паузе рисует обновлённый кадр. Возобновление вызывает
`play('HeroActions')`, который сам запускает рендер. Повторный `resume()`
не перезапускает действие. Пауза и reduced motion принадлежат проигрывателю;
пищевые состояния и награды в риг не входят.

## Устройство и сохранность исходников

Основа — сохранённый снимок
[hero-from-editor.rml](../hero-wardrobe/references/hero-from-editor.rml).
Скопированы контуры лица, волос, кистей и корпуса с их ручными локальными
трансформациями. Корпус походного комплекта взят из существующего черновика
одежды. Контуры плеч, предплечий, бёдер, голеней и ботинок подготовлены как
новые черновые части для артикуляции.

Общие узлы `Body`, `Upper body`, `Left/Right shoulder`, `Left/Right elbow`,
`Left/Right hip`, `Left/Right knee`, `Left/Right ankle` управляют обеими одеждами.
Одежные формы вложены в суставы. `Right hand socket` содержит кисть и отдельный
`Marshmallow stick`, поэтому палочка следует за рукой. `Program placement`
расположен выше всех суставов и управляется только программными координатами.

Слой `Action` меняет только трансформации; `Outfit` и `Prop` меняют только
прозрачность своих деталей. Каждое действие задаёт полный набор трансформаций,
чтобы прерывание посадки или возвращение к покою не оставляло старую позу ноги.
Дыхание отделено от нижней части: стопы в `idle`, `sit` и `reach` неподвижны.

`make_draft.py` — генератор исходной заготовки. При существующем `scene.rml`
он отказывается его перезаписывать; `--replace-draft` нужен только для явного
повторного создания этой технической заготовки и уничтожит ручные правки
**в этой папке**. Мастера `hero-editable`, `hero-wardrobe` и облако не затрагиваются.
Паспорт и SHA-256 исходного снимка — [manifest.json](manifest.json).

## Проверка и пересборка

Rive CLI 1.8.0 восстановлен из официального установщика во временную папку
`/tmp/chewy-rive-cli`; shell-профиль и пользовательские настройки не менялись.
Нужны Python, Pillow и NumPy. Выполнить из корня проекта:

```sh
python3 content-pipeline/rive/hero-actions/check_rig.py --rive /tmp/chewy-rive-cli/bin/rive
```

Команда проверяет сохранённый RML, собирает `.riv`, делает реальные CLI-рендеры
восьми сочетаний действия и одежды, сохраняет кадры и [QA](exports/qa.json).
Проверки доказали:

- Смена `camp → trail → camp` во время ходьбы сохраняет фазу попиксельно.
- Включение и выключение палочки сохраняет фазу ходьбы попиксельно.
- `sit → idle` возвращает полную спокойную позу, сохраняя одежду и реквизит.
- Цикл ходьбы замыкается; разные фазы реально меняют конечности.
- Стопы неподвижны при дыхании в покое, сидении и вытянутой руке.
- Программный перенос корня сохраняет действие и текущую фазу.
- Все сочетания действий, одежды и отражения помещаются на обоих краях
  заявленного диапазона положения, включая вытянутую палочку.
- Посадку можно прервать другим действием.
- Сборка и QA не меняют исходный снимок или редактируемый `scene.rml`.

CLI verify: без ошибок и предупреждений; inspect: без problems.

Браузерная проверка также пройдена. Из `prototype` при запущенном Storybook:

```sh
node scripts/check-hero-actions.mjs http://127.0.0.1:6007
```

Проверены реальные изменения кадров и остановка на паузе, смена одежды и
реквизита, прерывание поз, положение/отражение, reduced motion, три ширины экрана,
восстановление после ошибки загрузки, вход через Storybook и сохранность
данных основного лагеря. Сборка Storybook проходит. [Запись управления](../../../docs/exports/chewy-hero-actions-2026-11-02.mp4)
сделана в этом браузерном стенде; в приложение передаётся `.riv`. Apple runtime
не проверен.

## Что ещё нужно для лагеря

Фронтальная проба проверяет контракт, а не художественную готовность. Зеркало
`facing` не заменяет полноценные боковые и задние ракурсы. Нужны доводка формы
суставов и перекрытий, направленная походка, устойчивый контакт шага с землёй
(в этой пробе нет IK), настоящие посадка/подъём и привязка таза к сиденью.
У текущего `sit` есть сгиб ног и смешивание поз, но это ещё не поставленный жест
посадки на бревно.

Полив, возня с рюкзаком, игра с питомцем и палатка используют будущие действия
того же рига. Нужны сменные хватательные кисти, лейка и другие предметы на
креплении руки; точки подхода и маски дверного проёма принадлежат сцене лагеря.
Эффекты воды/огня и визуальные события начала/конца действия пока не добавлены.
Одежда сейчас представлена двумя полными наборами; независимые слоты, волосы
и головные уборы в этой пробе не проверялись.
