# Базовый костёр Chewy · проба Rive

По запросу владельца 30 октября 2026 взят существующий
[`fire.png`](../../../prototype/public/assets/sandbox/camp-v3-flat/fire.png).
Это отдельная векторная перерисовка по его контурам и один цикл активного огня.
Рисунок и движение — черновик для ревью; финальная художественная приёмка впереди.

В `.riv` сохранены три независимых контура огня, перекрещенные поленья,
срезы и линии древесины. Растровых кадров, скриптов, фоновой заливки и новых
предметов в нём нет. Двигаются вершины пламени и управляющие точки кривых;
поленья и положение всего предмета неподвижны. Фактура исходника упрощена
до векторных заливок с мягкими градиентами; это не пиксельная копия PNG.

## Контракт

- Artboard и state machine: `CampfireBase`.
- Одна анимация: `Living fire`, шестисекундный цикл. Языки огня вытягиваются,
  загибаются и меняют ширину; боковые языки и сердцевина движутся с разными
  фазами. Общий поток связывает контуры, корни закреплены за поленьями.
- Холст исходника: 1312 × 1199. Видимый рисунок примерно в пределах
  x=280…1035, y=98…1105; при посадке учитывать прозрачные поля.
- Для reduced motion проигрыватель должен остановить движение. Исходный
  кадр уже содержит полный рисунок; отдельного входного параметра в пробе нет.
- Пять ступеней наполнения, ночь и реакция на еду сюда пока не добавлены:
  сначала ревью одного цикла. Порогов и изменений игровых правил нет.

`exports/campfire-base.riv` занимает 181 806 байт. Размер runtime и приложения
в это число не входят. Фон, подписи и исходный PNG добавлены только в сравнение;
превью не заменяет сам `.riv`. `runtime-dark.png` — технический скриншот CLI
на его непрозрачном фоне, не прозрачный постер для приложения.

## Воспроизвести

Проверено с Rive CLI 1.8.0, Python 3 с Pillow/NumPy, ffmpeg и Noto Sans.

```sh
python content-pipeline/rive/campfire-base/generate_scene.py
rive content-pipeline/rive/campfire-base --verify
rive inspect content-pipeline/rive/campfire-base --summary
rive content-pipeline/rive/campfire-base --once
cp content-pipeline/rive/campfire-base/build/campfire-base.riv content-pipeline/rive/campfire-base/exports/campfire-base.riv
python content-pipeline/rive/campfire-base/render_previews.py --rive /path/to/rive
```

`art.py` хранит геометрию и палитру; `generate_scene.py` — движение и сборку
RML. Генератор перезаписывает `scene.rml`, поэтому правки вносятся в Python.
Ключи положения замкнуты; между ними runtime интерполирует линейно.
`render_previews.py` снимает настоящую state machine через CLI. Первый tick
вводит её в состояние, следующие продвигают анимацию. Кадры рендерятся в
размере исходника и уменьшаются так же, как PNG слева. Экспорт не содержит
дублирующего последнего кадра петли.

CLI verification и inspect прошли без ошибок, предупреждений и problems.
В отрисованных кадрах проверены движение огня, неподвижность нижней части
поленьев и совпадение начала/конца с допуском на растеризацию. Машинный отчёт —
в `exports/qa.json`. Проверены светлый и тёмный фон и четыре фазы цикла.

Проба не подключена к основному лагерю или Storybook. Apple runtime,
память, батарея и производительность на iPhone не проверены; Xcode в текущем
окружении отсутствует. Исходный PNG и прежние пробы сохранены.

Владелец положительно оценил рисунок и попросил перейти к анимации. Более
заметное горение подготовлено без изменения `art.py`; новое движение ждёт
ревью. Предыдущий спокойный цикл и его генератор сохранены в
`exports/initial-motion/`. Геометрия дополнительно проверена в 361 фазе:
видимые контуры не пересекаются, цветные слои остаются вложенными.
