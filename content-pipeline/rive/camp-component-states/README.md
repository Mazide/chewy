# Пять состояний компонентов лагеря · Rive

Черновая примерка от 6 ноября 2026: палатка, рюкзак и растительность рядом
с прежней пробой костра. Каждый предмет — настоящий `.riv` с пятью состояниями,
ручным управлением `stage` и плавным переходом. Пороги еды не задаются.

## Посмотреть

Storybook → **Мастерская / Лагерь · пять состояний Rive** или `/camp-states/index.html`
на сервере прототипа. У каждого предмета отдельный выбор; верхний ряд меняет все
предметы сразу. «Новый день» возвращает первую ступень. Есть пауза, настройка
reduced motion и повтор загрузки после ошибки. Проба не читает и не записывает
демосессию, покупки или раскладку владельца.

## Контракт и образы

| Ассет | Artboard / state machine / view model | Образ пяти ступеней |
|---|---|---|
| [Палатка](exports/tent.riv) | `TentStates` | Прикрытый вход → щель → наполовину открытый → почти открытый → полностью раскрытый. Ткань движется всё заметнее; колышки, растяжки и опора неподвижны |
| [Рюкзак](exports/provisions.riv) | `ProvisionsStates` | Закрытый → первый свёрток → несколько свёртков → наполнен → запас сверху. Свёртки слегка покачиваются; корпус и фурнитура сохраняются |
| [Растительность](exports/plants.riv) | `PlantStates` | Компактный росток → расправляющийся → боковые побеги → цветок → пышная зелень и несколько цветов. Один и тот же горшок |
| [Костёр](exports/campfire.riv) | `Campfire` | Прежние пять состояний; файл скопирован без изменения из `../campfire/exports` |

Числовое свойство view model `stage` принимает целые значения `0…4` — внутренний
индекс состояния, не число питания. Новые ассеты начинают со `stage=0`.
У прежнего костра значение по умолчанию `2`; просмотрщик устанавливает `0`.
Переходы новых ассетов — 400 мс, циклы — 6 секунд. Это параметры визуальной
пробы. Для reduced motion просмотрщик применяет состояние, завершает переход
и останавливает отрисовку. Все ступени различимы без движения.

Палатка связана с белком, растительность — с овощами и фруктами. Связь рюкзака
с углеводами остаётся рабочей гипотезой. Новые детали показывают дневную
активность; они не выдают предметы инвентаря. Сочетание состояний с купленными
оформлениями и посадка в основном лагере ещё требуют отдельной примерки.

## Источники и сборка

Палатка переиспользует `../camp-scene-vector/tent_art.py`; её прежний мастер
не изменяется. Геометрия рюкзака экспортируется из `CampProvisions.jsx` в пять
SVG-референсов, затем переносится в редактируемые Rive-контуры. Растения —
новая векторная проба по образу горшка из текущего лагеря. Растровых кадров
и скриптов внутри новых `.riv` нет. В Rive остаются отдельные контуры и слои.
У рюкзака пять групп рисунка смешиваются по прозрачности, свёртки анимированы
внутри групп; у палатки меняется контур полога, у растений — позы побегов.

Для обычного выпуска **из сохранённых исходников**, включая ручные правки:

```sh
python3 content-pipeline/rive/camp-component-states/build.py --rive /path/to/rive
```

Проверено с [Rive CLI 1.8.0](https://rive.app/docs/cli/getting-started).
Сборка проверяет RML/контракт, компилирует `.riv` и сохраняет хеши источников.
Она не запускает генератор и проверяет сохранность исходного `scene.rml`.

Только для намеренной регенерации рисунка и движения (**перезаписывает RML**):

```sh
node prototype/scripts/export-provision-vectors.mjs
python3 content-pipeline/rive/camp-component-states/generate.py
```

Python-генератор использует стандартную библиотеку. Экспорт SVG требует
установленных зависимостей прототипа. Веб-просмотр использует уже сохранённый
в проекте Rive WebGL2 2.40.1; внешняя сеть во время просмотра не нужна.

## Проверка

```sh
cd prototype
npm run build
node scripts/check-camp-states.mjs http://127.0.0.1:6010
```

Проверяются настоящие кадры: пять различных состояний каждого предмета,
правильный начальный кадр, возврат `0 → 4 → 0`, независимость управления,
движение, пауза и переключение при reduced motion. Дополнительно — три мобильные
ширины, зоны нажатия, восстановление загрузки, вход из Storybook и сохранность
данных основной сессии. QA-снимки сохраняются в `/tmp/chewy-camp-states`.

Художественная приёмка, основной лагерь и Apple runtime ещё впереди.
Анимации Чуви в эту пробу не входят.
