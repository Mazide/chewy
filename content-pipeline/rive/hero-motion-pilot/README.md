# Чуви машет рукой · проба Rive

Короткое приветствие на сохранённом ручном рисунке Чуви: подготовка,
подъём руки, два взмаха и возвращение к исходной позе. Это отдельный черновик
для оценки движения; новый жест не подключён к событиям основного лагеря.

## Контракт и исходники

| Элемент | Значение |
|---|---|
| Artboard / state machine / view model | `ChewyMotion` |
| Number property | `action`: `0` — покой, `1` — приветствие |
| `Idle` | Спокойный цикл, 4 секунды |
| `Wave` | Однократный жест, 4,8 секунды, конец совпадает с исходной позой |
| Холст | 760 × 1120 |
| Рабочий мастер | [chewy/scene.rml](chewy/scene.rml) |
| Исходная поза для сравнения | [baseline/scene.rml](baseline/scene.rml) |
| Бриф | [motion-brief.json](motion-brief.json) |
| Проверка рига и исходного рисунка | [evidence/authoring.json](evidence/authoring.json) |

Основа — [снимок ручного мастера](../hero-wardrobe/references/hero-from-editor.rml).
Положение верхней части из него сохранено. Брюки и ботинки неподвижны.
Для приветствия добавлена черновая открытая ладонь; в исходной позе и в конце
остаётся прежняя кисть на поясе. Её контур отдельно требует художественного ревью.
Старые мастера `hero-editable`, `hero-wardrobe` и `hero-actions` не пересоздаются.
Финальный рисунок и художественная приёмка остаются за владельцем.

25 из 26 исходных фигур сохранены полностью. У правого рукава исходная кривая
разбита на участки без изменения формы и привязана весами к плечу/предплечью;
стык у корпуса закреплён отдельно. Ладонь следует за запястьем. Начальная
и конечная позы совпадают попиксельно; небольшой сдвиг головы, дыхание и моргание
заданы ключами, ноги не входят в анимацию.

## Повторить выпуск

```sh
python3 content-pipeline/rive/hero-motion-pilot/pipeline.py run
```

CLI задаётся через `--rive /path/to/rive`, `RIVE_CLI` или `PATH`; в этой среде
также распознаётся `/tmp/chewy-rive-cli/bin/rive`. Версия закреплена: **1.8.0**.
Python-зависимости — [requirements.txt](requirements.txt), Playwright — из
`prototype/package-lock.json`; нужны Chromium и FFmpeg. Настройка окружения
описана в [предыдущем пилоте](../motion-pilot/README.md#повторить-весь-локальный-прогон).
Веб-рендерер — сохранённый Rive WebGL2 2.40.1.

Использована изолированная копия проверенного runner из пилота растений:
он читает сохранённые RML, собирает временные копии, проверяет `verify`/`inspect`,
рендерит фазы, проверяет сохранность видимой правки после двух сборок и запускает
браузерную проверку с записью видео. Генератор рисунка при выпуске не вызывается.
Исходный неподвижный образ отдельно исключён из требования «анимация движется».

`exports/latest.json` указывает на последний успешный выпуск. Внутри
`exports/runs/<id>/` лежат `chewy.riv`, `baseline-chewy.riv`, снимки исходников,
`manifest.json`, конфигурация `reproduce.json`, кадры и `browser-qa/review.mp4`.
Неудачный полный прогон не заменяет прежний указатель.
Команда `build` делает только техническую сборку; это явно отражено в статусе.

Для повторной сборки сохранённого выпуска:

```sh
python3 content-pipeline/rive/hero-motion-pilot/pipeline.py build --config content-pipeline/rive/hero-motion-pilot/exports/runs/<id>/reproduce.json --output /tmp/chewy-hero-rebuild
```

Регрессии runner:

```sh
python3 content-pipeline/rive/hero-motion-pilot/test_pipeline.py
```

## Границы проверки

Локальные кадры и браузерный прогон проверяют воспроизведение, неподвижные стопы,
края, паузу, повтор жеста, reduced motion и возврат к нейтральной позе.
Эти проверки не оценивают выразительность жеста автоматически.

В [независимом аудите](evidence/independent-source-review.json) проверены 19 фаз
через CLI: нижняя часть неподвижна, фигура остаётся связной, через 4,8, 6 и 9,6
секунды видна одна и та же исходная поза. Жест не зацикливается и без таймера
просмотрщика. [Вход из собранного Storybook](evidence/storybook.json) и 12
регрессий runner прошли. Браузер отдельно проверил смену reduced motion во время
жеста, мобильную ширину и повторную загрузку после ошибки.

Реальная ручная правка в Rive Editor и Apple runtime пока не проверены.
При отсутствии CLI-авторизации шаг `.rev` отмечается `blocked_by_auth`;
если вход доступен, runner проверит локальный круг формата `.rev`, но это
по-прежнему не ручная доводка в Editor. В облачный аккаунт ничего не отправляется.
