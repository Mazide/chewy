# Ручная доводка героя

Рабочий источник героя для пробы лагеря — [scene.rml](scene.rml).
Он выделен из проверенной сцены без изменения рисунка и анимации.
Сборка лагеря теперь читает этот документ и не перезаписывает его.
`camp-scene-vector/hero_art.py` остаётся историей создания заготовки.

## Передать в Rive Editor

Герой уже загружен в `chewy → Personal Files` и открыт в режиме Design:
[hero-editable в Rive](https://editor.rive.app/file/hero-editable/2696405).
Первичная загрузка выполнена через `rive push`, ссылка на облачный файл
сохранена в `rive.yaml`. Повторный push заменяет облачные правки — не выполнять
его поверх ручной работы без предварительного получения актуального источника.

В текущем окружении CLI установлен в `/tmp/chewy-rive-cli/bin/rive`.
Для экспорта редактируемого `.rev` Rive CLI требует вход в аккаунт:

```sh
rive login
python content-pipeline/rive/hero-editable/manage.py export
```

Полученный `exports/hero-editable.rev` открыть в Rive Editor. Runtime `.riv`
служит для воспроизведения; для ручной доводки передаём исходный `.rev`.
Команда экспортирует локальный файл, не создаёт проект в облачном workspace.

В веб-редакторе открыть **Personal Files** и перетащить туда
`exports/hero-editable.rev` из файлового менеджера. Перетаскивать в список
файлов, до открытия документа. Затем открыть импортированный файл.

В режиме Design выбрать нужную фигуру и нажать Enter дважды; если выбран
непосредственно Path — Enter один раз. Редактировать точки и ручки кривых,
завершить через Done Editing.
Оригинал для сверки: [original-hero.png](references/original-hero.png).
В режиме Animate проверить дыхание, наклон головы и моргание.

| Что править | Названия слоёв |
|---|---|
| Волосы | `Front golden hair`, `Back hair` |
| Лицо | `Face and neck`, `Easy smile`, `Left eye`, `Right eye` |
| Руки | `Left sleeve`, `Right sleeve`, `Left hand`, `Right hand`, отдельные линии пальцев |
| Одежда | `Linen shirt`, `Blue trousers`, `Left boot`, `Right boot`, линии ткани и обмоток |

Для первого прохода менять форму контуров и цвета, сохраняя группы
`Head pivot`, `Head geometry`, `Breathing upper body`, artboard `Hero` и
state machine `Hero`. Голова с шеей пока объединены в один контур.
Движение задаётся четырьмя дорожками трансформаций; вершины волос, лица,
рук и одежды не имеют собственных ключей и доступны для доводки рисунка.

## Вернуть исправления

Скачать исправленный редактируемый `.rev` из редактора и импортировать:

В редакторе это **Export → For backup**. По текущей документации Rive
экспорт backup доступен на платных планах; перед ручной доводкой проверить
его доступность в своём аккаунте:
https://rive.app/docs/editor/exporting/exporting-for-backup.

```sh
python content-pipeline/rive/hero-editable/manage.py import /path/to/edited-hero.rev
python content-pipeline/rive/camp-scene-vector/build_scene.py
python content-pipeline/rive/camp-scene-vector/render_previews.py
```

Импорт сначала открывает файл в отдельной временной папке, проверяет контракт
и сборку, затем сохраняет предыдущий источник в `history/*.rml.bak` и заменяет
рабочий документ. Новый файл с другими artboard, внешними зависимостями,
растровыми ассетами или скриптами отклоняется: этот проход предназначен для
ручной правки существующего героя. При ошибке прежний источник сохраняется.

Сборка лагеря меняет ID только у копии героя в памяти; исходник редактора и его
ID остаются нетронутыми. `namespace-map.json` сохраняет соответствие пространств
ID при последующих сборках. После пересборки обновить страницу просмотрщика.
