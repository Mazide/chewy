# Костёр · первая векторная проба Rive

Отдельный образец для выбора технологии, сделан 30 октября 2026 по запросу
владельца. Арт и характер движения — черновик для ревью. Порогов игрового
наполнения здесь нет; стадии переключаются вручную.

## Посмотреть

- [Пять состояний](exports/contact-sheet.png).
- [Видео с переходами](exports/preview.mp4).
- [Ассет для runtime](exports/campfire.riv).

Рисунок и движение созданы векторно в RML: три контура пламени, поленья,
камни, угли, свечение земли, две искры и запас дров. Верхние вершины контуров
двигаются независимо; основание и поленья неподвижны. Это настоящая анимация
Rive, превью снято CLI из того же исходника.

## Контракт

Artboard, state machine и view model называются `Campfire`.
View model содержит числовое свойство `stage`; допустимы целые значения:

| Значение | Состояние владельца | Изображение |
|---|---|---|
| `0` | Спящее | Собранный очаг, тёмные угли, без пламени |
| `1` | Нормальное, но начало | Маленькое пламя и тёплые угли |
| `2` | Активированное | Выше и шире пламя, появляется светлая сердцевина |
| `3` | Ещё немного более активированное | Полное пламя и редкие искры |
| `4` | Профицит | Полный огонь и небольшой запас дров сбоку |

Спящее — первая ступень дневного наполнения, не ночной режим.
`stage` по умолчанию равен `2`. Переходы смешиваются за 400 мс, циклы длятся
четыре секунды. Это параметры движения образца, не тюнинг игровой прогрессии.
Ночные состояния, реакция на лог и купленное оформление пока не реализованы.
Для reduced motion можно остановить проигрывание после выбора стадии:
различия видны в статике; отдельного параметра reduced motion в ассете нет.

В `.riv` нет фоновой заливки или растровых изображений. Зелёный фон и подписи
добавлены только в превью. Артборд 400 × 400; при примерке размер следует
считать по видимому рисунку, а не по пустым полям артборда.

## Изменить и собрать

Требуется Rive CLI 1.8.0. `generate_scene.py` — источник геометрии, палитры
и ключей; он воспроизводит редактируемый `scene.rml` без внешних зависимостей.
Правки RML вручную допустимы, но повторный запуск генератора их перезапишет.

```sh
python3 generate_scene.py
rive . --verify
rive inspect . --summary
rive . --once
cp build/campfire.riv exports/campfire.riv
rive . --data=stage=3
```

Последняя команда открывает живое окно Rive с пересборкой при сохранении.
В текущем Linux-окружении нет X display; вместо окна проверены headless-рендеры.
Инструкция воспроизведения кадров/видео — в `render_previews.py --help`.

`scene.rml` — редактируемый исходник CLI; `.riv` — скомпилированный runtime-ассет.
Редакторский `.rev` не экспортирован: этот путь CLI требует входа в аккаунт.
Публикации и загрузки в аккаунт Rive не выполнялись. Скриптов внутри ассета нет.

## Проверено и что осталось

CLI verification: без ошибок и предупреждений; inspect: пять animation states,
пять timelines, один state machine, view model `stage`, без problems.
Возврат `0 → 4 → 0` даёт исходный кадр без остаточного пламени/запаса.
Кадры внутри цикла меняют огонь, сохраняя неподвижность основания и поленьев;
стык четырёхсекундного цикла проверен соседними кадрами без скачка.

В текущий лагерь, Storybook и iOS ассет ещё не встроен. Нужно ревью рисунка
и движения, затем примерка в реальном масштабе лагеря и проверка Apple runtime.
Эта проба не выбирает Rive для всего проекта и не закрывает сравнение с растром
или смешанным подходом.
