# Три состояния компонентов лагеря · Rive

Визуальная проба от 6 ноября 2026 по выбранным владельцем образам. Четыре
редактируемых `.riv`, у каждого три состояния. Исходные PNG и предыдущая
пятиступенчатая проба в `../camp-component-states/` сохранены без изменений.

## Посмотреть

Storybook → **Мастерская / Лагерь · три состояния Rive**.
Прямой вход: `/camp-states/states.html`; все состояния рядом:
`/camp-states/compare.html` на сервере прототипа.

Основная интеграция: **Прототип / Приложение**, обычные фото, моковый разбор,
дневник и смена дня. Базовые предметы получают `stage` из сохранённых результатов;
случайный тестовый состав сохраняется с задачей. Примерка с мгновенной кнопкой
еды сохранена в **Мастерская / Лагерь · день с едой**, `/camp-meals.html`.
Размер лампы и растений уменьшен по ревью. Купленные оформления сада пока
сохраняют прежний рисунок, их Rive-варианты ещё не подготовлены.

- [Таблица двенадцати настоящих кадров Rive](../../../docs/exports/chewy-camp-three-states-2026-11-06.png).
- [Движение и переходы](../../../docs/exports/chewy-camp-three-states-2026-11-06.mp4).
- [Паспорт исходников и экспорта](exports/manifest.json).
- [Результат браузерной проверки](exports/qa-browser.json).

Можно менять каждый компонент отдельно или все вместе, остановить движение,
вернуть начало дня. Проба не читает и не меняет основную демосессию, раскладку
или инвентарь. Пищевые пороги не заданы; художественная приёмка, подключение
в Apple runtime остаётся отдельно; основной веб-лагерь подключён.

## Образы и источники

| Ассет / связь | Начало дня | В процессе | Полное | Исходный растр |
|---|---|---|---|---|
| Палатка / белок | Полусложенная ткань у основания | Поднимающийся каркас и провисающая ткань | Собранная палатка | `prototype/public/assets/sandbox/camp-v3-flat/tent.png` |
| Костёр / углеводы | Маленький огонь | Огонь выше | Полное яркое пламя | `prototype/public/assets/sandbox/camp-v3-flat/fire.png` |
| Растения / овощи и фрукты | Росток в траве | Листья, стебли и первая ромашка | Пышная группа ромашек | `prototype/public/assets/screen-studies/flowers.png` |
| Лампа / жиры | Мало масла и слабый огонёк | Масло и свет прибавляются | Полный резервуар и яркое свечение | `prototype/public/assets/screen-studies/lantern.png` |

Палатка и огонь используют прежние ручные векторные обводки. У палатки меняются
контуры ткани и высота сборки, колышки стоят на месте. У огня неподвижны поленья,
движутся независимые контуры трёх цветов. Растения перерисованы по ромашкам,
лампа — по зелёному корпусу: добавлены видимые фитиль и окошко масла.
Текстура исходного растра упрощена до векторных заливок; это черновой перенос.

## Контракт

| Файл | Artboard / state machine / view model |
|---|---|
| [tent.riv](exports/tent.riv) | `TentStates` |
| [campfire.riv](exports/campfire.riv) | `CampfireStates` |
| [plants.riv](exports/plants.riv) | `PlantStates` |
| [lamp.riv](exports/lamp.riv) | `LampStates` |

Числовое свойство `stage`: `0`, `1`, `2`, исходное значение `0`.
Анимации: `Morning`, `Growing`, `Full`; цикл шесть секунд, переход 550 мс.
Это параметры визуальной пробы, не пищевые числа. В режиме reduced motion
просмотрщик останавливает state machine и показывает нулевой кадр выбранной
анимации через `scrub`. Кадр воспроизводится одинаково после возврата и перезагрузки.
Пауза останавливает текущую позу, выбор новой ступени при паузе показывает
её фиксированный вид. Все состояния различимы без движения.

## Сборка и проверка

Обычная сборка читает сохранённые мастера, не запускает генератор и проверяет,
что байты RML не изменились:

```sh
python3 content-pipeline/rive/camp-daily-states/build.py --rive /tmp/chewy-rive-cli/bin/rive
cd prototype
npm run build
node scripts/check-camp-states.mjs http://127.0.0.1:6010
node scripts/capture-camp-daily-states.mjs http://127.0.0.1:6010
node scripts/record-camp-states.mjs http://127.0.0.1:6010
```

CLI: Rive 1.8.0; браузер: сохранённый Rive WebGL2 2.40.1. Для локальной
проверки сервер раздаёт `prototype/storybook-static` на указанном порту.
Выпуск сохраняет SHA-256 растровых референсов и RML, размеры файлов и проверки
CLI в `exports/manifest.json`. Браузерный QA сохраняет кадры и отчёт в
`/tmp/chewy-camp-states/`; видеозапись — в `/tmp/chewy-camp-states-video/`.

Только для намеренного пересоздания рисунка и движения (**перезаписывает
четыре локальных мастера**, не трогает прежние пробы):

```sh
python3 content-pipeline/rive/camp-daily-states/generate.py
```

Растровые референсы не редактируются; новые ассеты состоят из векторных деталей,
ключей анимации и машины состояний. Внешние генерации и платные API не нужны.
